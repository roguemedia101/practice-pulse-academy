# Editable 12-Line Python Demo

## Goal
Turn the hero practice workspace into an editable, 12-line Python demo that runs a lightweight browser simulation.

## Changes
- Replace the fixed code display with a multiline editor capped at 12 lines.
- Keep the current greeting example prefilled as the editor's starting code.
- Keep visible line numbers and prevent additional pasted or typed lines.
- Simulate useful beginner Python behavior for variable assignments, `print(...)`, f-strings, and the included greeting function.
- Show friendly output or a clear simulated syntax/error message in the existing terminal.
- Preserve the current visual design, Run interaction, mobile layout, and frontend-only scope.

## Validation
- Test editing, the line limit, successful output, error output, and mobile/desktop layout.
- Confirm the preview remains error-free.
